# AI Drone Delivery Landing Page

A modern, responsive landing page for an AI-powered drone delivery business.

## Overview

This landing page showcases the services of an AI drone delivery company, featuring a dark theme with custom colors.

## Features

- **Hero Section**: Eye-catching introduction with call-to-action button
- **About Section**: Information about the company's AI technology
- **Services Section**: Highlights key delivery services
- **Contact Form**: Simple form for user inquiries
- **Responsive Design**: Works on desktop and mobile devices

## Color Scheme

- Primary Background: #080c14
- Secondary Background: #0e1422
- Accent Blue: #00aaff
- Accent Orange: #ff6600
- Dark Elements: #1a1f2e

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

1. Clone or download the project files
2. Open `index.html` in your web browser
3. The page is ready to view and interact with

## Customization

- Edit `style.css` to modify colors and styling
- Update `index.html` to change content
- Add functionality in `script.js`
